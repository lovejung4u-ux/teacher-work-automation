1 문제 파일

한글 · PDF · Word · Excel · PowerPoint · 캡처/사진 · 텍스트 / 5MB 이하

첨부된 파일 없음

한글·문서의 본문 텍스트를 읽습니다. HWP 수식 개체·그림·복잡한 표는 누락될 수 있으니 원문과 대조해 보완하세요. 정답이 없으면 AI 풀이를 교사가 확인해야 합니다.

2 학생별 정오표

엑셀 · 한글 · Word · PDF · 캡처/사진(PNG·JPG·WEBP) / 5MB 이하

첨부된 파일 없음

행·열 배치가 다른 표와 학생별 여러 행 구조를 읽습니다. 정오표의 ○/×/△를 구분하고, 배치가 복잡한 문서·이미지는 AI 인식을 사용합니다. AI 인식 결과는 확인 후 분석에 사용하세요.

선택 설정 · 과목·학년·분석 조건

참고자료 · 평가기준·교과서·교육과정 (선택)

여러 자료를 함께 추가할 수 있습니다. 파일당 5MB, 최대 10개. 문서의 읽힌 본문을 요청문에 포함합니다. 수식·그림·스캔 자료는 원본을 GPT에도 직접 첨부하세요.

3 · GPT에서 학생별 보고서 파일 바로 만들기

전문 보고서 방식: 핵심 진단·근거·해석·학습 처방을 담은 본문(4~6쪽 안팎)과 개념·보충문제·해설 워크북을 분리하고 각각 편집용 DOCX·배포용 PDF로 요청합니다. 참고 보고서 PDF도 함께 첨부하면 디자인을 더 정확히 맞출 수 있습니다. 파일 생성 기능이 있는 GPT 대화에서 사용하세요.

API 키 없이 사용합니다. 요청문을 복사해 본인 계정의 AI에 붙여 넣으세요. 사진·PDF·수식·복잡한 표는 원본 파일도 AI 대화창에 직접 첨부하세요. 이 사이트가 AI 대화나 파일을 자동으로 가져오지는 않습니다.

4 · 선택 사항: JSON 결과를 웹페이지 보고서로 만들기

GPT 답변 아래의 복사 버튼을 누른 뒤 이곳에 답변 전체를 붙여 넣으세요. 설명과 코드 상자는 자동으로 구분합니다. 파일로 저장할 필요가 없습니다. 한 번에 최대 100명이며, 인식한 학생·문항·정오를 원본과 대조해 주세요.

선택 · 기존 Gemini API 연결 사용

기존 상세 입력·AI 결과 붙여넣기

피드백 자료 입력

📎 파일에서 자료 가져오기

한글(HWP·HWPX·HML) · PDF · Word · Excel · PowerPoint · ODT · HTML · TXT·CSV·JSON / 파일당 5MB, 최대 5개

파일은 브라우저에서 읽습니다. 추출 내용을 아래에서 확인·익명화한 후 AI를 실행하세요. 일반 HWP 5.x·HWPX 본문을 지원합니다. 암호·배포용·DRM 문서와 구형 HWP 3.x는 읽지 못합니다. 사진·스캔 PDF는 OCR 후 올려 주세요. 구형 DOC·PPT·RTF는 DOCX·PPTX·PDF로 변환해 주세요. 수식·표의 배치는 달라질 수 있습니다. 엑셀은 표시된 시트의 저장된 셀 값을 읽으며 수식을 다시 계산하지 않습니다. 숨김 시트·이미지·차트는 제외됩니다.

여러 학생은 [학생 A], [학생 B]로 구분하세요. 이름·학번·연락처는 입력하지 마세요.

입력 자료는 자동 저장하지 않습니다. AI 실행 시 자료가 Google Gemini로 전송됩니다. 무료 서비스는 입력·출력을 서비스 개선에 사용할 수 있으므로 개인정보·민감정보·비공개 자료는 제외하세요.

학생별 결과분석 보고서

0명

학생별 초안을 수정한 뒤 검토 완료를 표시하세요. 학생 이름은 AI 생성 후 여기에서 직접 바꿀 수 있습니다. 보고서는 이 창에만 보관됩니다.

문제·정오표로 생성된 보고서는 이곳에서 학생별로 수정할 수 있습니다. AI 연결 전에는 빈 보고서를 직접 작성하거나, ‘요청문 만들기’로 받은 JSON 결과를 위 결과란에 붙여 넣고 ‘결과에서 보고서 가져오기’를 누르세요. 인쇄 창에서 ‘PDF로 저장’을 선택할 수 있습니다. 수정본 JSON에는 학생 자료가 들어갈 수 있으니 별도로 보관하세요.

아직 보고서가 없습니다. AI 생성 시 학생마다 별도 보고서가 표시됩니다.

처음 사용하시나요? · AI 연결 안내
  1. ‘예시 넣기’로 입력 형식을 확인한 뒤 학생 자료를 익명으로 입력하세요.
  2. AI 연결 전에도 ‘요청문 만들기’를 누르면 ChatGPT·Gemini에 붙여 넣을 요청문을 만들 수 있습니다. 이는 AI 분석 결과가 아닙니다.
  3. 웹페이지 안에서 AI를 실행하려면 저장소의 server.gs를 Google Apps Script에 붙여 넣고, 스크립트 속성에 GEMINI_API_KEY와 ACCESS_TOKEN을 설정하세요. 자세한 절차는 파일 상단에 있습니다.
  4. 웹 앱으로 배포한 주소와 직접 정한 이용 암호를 ‘AI 연결 설정’에 입력하세요. API 키를 GitHub에 올리지 마세요.
  5. 무료 한도 초과 시 실행이 중단됩니다. 모델별 무료 제공 여부·한도는 Google 공식 안내에서 확인하세요.

AI 연결 설정

무료 이용 구간이 있는 Gemini API를 별도 연결 서버를 통해 사용합니다. 연결 주소만 이 브라우저에 저장하며, 암호와 학생 자료는 저장하지 않습니다.

API 키는 이 화면에 입력하지 않습니다. 서버의 스크립트 속성에만 보관하세요.
